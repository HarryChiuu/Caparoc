# Reconnect 功能說明

## 📅 更新日期
2025年11月4日

## 🎯 新增功能
在 CLI 互動命令中新增 `reconnect` 指令，允許使用者在連線失敗或斷線後，無需重啟程式即可重新嘗試連接設備。

## ✨ 功能特點

### 1. Reconnect 指令
在主選單中輸入 `reconnect` 即可重新執行連線與初始化流程。

### 2. 自動清理
執行 reconnect 前會自動：
- 停止正在運行的監控執行緒
- 釋放現有的 driver 連線
- 重新初始化所有狀態

### 3. 完整重新初始化
Reconnect 會重新執行完整的啟動流程：
- 步驟 0: 裝置連線檢查
- 步驟 1: 全域系統狀態檢查
- 步驟 2: 設備狀態同步
- 步驟 3: 顯示互動選單

## 📋 使用場景

### 場景 1: 初始連線失敗
```
============================================================
🔌 檢查裝置連線...
============================================================

❌ 裝置連線失敗!
   IP 位址: 192.168.2.111
   錯誤: 無法建立連線

💡 請檢查:
   1. 設備是否已開機
   2. 網路線是否正確連接
   3. IP 位址是否正確 (當前: 192.168.2.111)
   4. 電腦與設備是否在同一網段
   5. 防火牆是否阻擋連線 (Port 44818)
```

**使用者動作**：
1. 檢查並修復連線問題（開機、插網路線等）
2. 程式已退出，需重新執行 `python src/caparoc_controller.py`

### 場景 2: 連線成功後中斷
```
> s
[顯示狀態...]

> on 1
❌ 連線錯誤: 設備無回應

> reconnect
🔄 嘗試重新連線...

[系統] 重新啟動連線與初始化流程...

============================================================
🔌 檢查裝置連線...
============================================================
✅ 裝置連線成功!
...
```

**使用者動作**：
1. 發現連線中斷
2. 檢查並修復問題
3. 輸入 `reconnect` 重新連線（不用重啟程式）

## 🔧 技術實作

### 修改的檔案
`src/caparoc_controller.py`

### 主要變更

#### 1. run() 方法返回值
```python
def run(self):
    """主程式"""
    # ...初始化與互動命令迴圈...
    
    while True:
        try:
            cmd = input("\n> ").strip().lower()
            
            if cmd == 'q':
                # 停止監控並退出
                if self.monitor_running:
                    self.stop_monitor()
                break
            
            elif cmd == 'reconnect':
                print("\n🔄 嘗試重新連線...")
                # 停止監控
                if self.monitor_running:
                    self.stop_monitor()
                return 'reconnect'  # ⬅️ 返回特殊值
            
            # ...其他命令...
```

#### 2. main() 函數支援重試
```python
def main():
    controller = CaparocController()
    while True:
        result = controller.run()
        if result == 'reconnect':
            print("\n[系統] 重新啟動連線與初始化流程...\n")
            continue  # ⬅️ 重新執行 run()
        break  # 正常退出或其他情況則結束
```

#### 3. 選單新增指令
```python
print("\n【系統】")

```

## ✅ 優點

1. **使用者體驗改善**
   - 不需要重啟程式就能重新連線
   - 節省時間，特別是在調試階段

2. **更靈活的錯誤恢復**
   - 網路暫時中斷後可快速恢復
   - 設備重啟後可立即重新連接

3. **開發階段便利**
   - 調試時不用反覆關閉重啟程式
   - 測試不同連線狀態更方便

## 💡 使用提示

1. **何時使用 reconnect？**
   - 設備重啟後
   - 網路暫時中斷恢復後
   - 命令執行失敗疑似連線問題時

2. **reconnect vs 重啟程式**
   - reconnect: 快速，保留 controller 實例
   - 重啟程式: 完全重置所有狀態

3. **注意事項**
   - reconnect 會停止正在運行的監控
   - 重新連線會重新同步設備狀態
   - 如果連線仍然失敗，程式會退出（需重啟）
