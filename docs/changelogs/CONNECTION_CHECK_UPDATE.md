# 裝置連線檢查機制 - 更新說明

## 📅 更新日期
2025年11月3日

## 🎯 更新目標
為 CAPAROC 控制器添加裝置連線檢查機制，在程式啟動時驗證設備是否可連接，若無法連接則顯示清晰的錯誤訊息和故障排除建議。

## ✨ 新增功能

### 1. 連線檢查方法 (`check_device_connection`)

新增了專門的連線檢查方法，用於驗證裝置連線狀態：

**功能特點:**
- 使用 CIP Identity Object (Class 0x01) 進行標準連線檢查
- 讀取設備基本資訊（產品名稱、設備類型等）
- 提供詳細的錯誤訊息和連線狀態回報

**實作位置:** `src/caparoc_controller.py` Line ~1918

**方法簽名:**
```python
def check_device_connection(self, driver):
    """
    檢查裝置連線狀態
    
    Returns:
        dict: {
            'connected': bool,      # 是否連線成功
            'error': str,           # 錯誤訊息 (如果有)
            'device_info': dict     # 設備資訊 (如果連線成功)
        }
    """
```

### 2. 啟動流程整合

將連線檢查整合到 `run()` 方法的啟動流程中：

**執行順序:**
1. **步驟 0: 裝置連線檢查** ⬅️ NEW!
   - 嘗試連接設備
   - 讀取設備資訊
   - 驗證連線狀態
   
2. 步驟 1: 全域系統狀態檢查
   - 檢查電壓、電流、模組數量
   - 檢查系統錯誤和警告
   
3. 步驟 2: 設備狀態同步
   - 讀取通道狀態
   - 同步控制緩衝區

## 🔧 技術細節

### 連線檢查機制
- **協定**: CIP (Common Industrial Protocol) via EtherNet/IP
- **檢查對象**: Identity Object (Class 0x01, Instance 1)
- **讀取屬性**:
  - Attribute 1: Vendor ID (必須有回應才算連線成功)
  - Attribute 7: Product Name (選用，用於顯示)
  - Attribute 2: Device Type (選用，用於顯示)

### 錯誤處理
- `ConnectionError`: 網路連線錯誤
- `TimeoutError`: 設備無回應
- 其他例外: 一般性連線失敗

### 安全性考量
- 連線失敗時程式**立即退出**，不會繼續執行
- 避免在無設備連線的情況下執行控制命令
- 保護使用者免於誤操作或混淆

   - 確保設備在 192.168.2.111 並已開機

2. **連線失敗測試**

   - 預期: 顯示連線錯誤並退出
