# CAPAROC Breaker CLI - 使用手冊

## 📋 概述

CAPAROC Breaker CLI 提供兩種控制方式：

### 🎮 互動式 Shell (推薦)
**`caparoc_shell.py`** - 程式啟動後持續運行，可隨時輸入命令控制
- ✅ 一次啟動，持續控制
- ✅ 即時命令回應
- ✅ 內建即時監控模式
- ✅ 友善的互動介面

### 🔧 單次命令模式
**`caparoc_cli.py`** - 每次執行一條命令
- ✅ 適合腳本自動化
- ✅ 批次處理
- ✅ 簡單快速

### 主要功能

- ✅ 即時監控電壓電流值
- ✅ 控制通道啟閉狀態
- ✅ 支援單通道或所有通道操作
- ✅ 即時監控模式（連續更新）
- ✅ 基於 Implicit Messaging (20Hz 實時通訊)


### 2. on - 開啟通道

開啟指定通道。

**語法**:
```bash
python src/caparoc_cli.py [--ip IP] on CHANNEL [--current AMPS]
```

**參數**:
- `CHANNEL`: 通道編號 (1-4)
- `--current`: 額定電流 (A, 預設: 4)

**範例**:
```bash
# 開啟通道 1 (使用預設 4A)
python src/caparoc_cli.py --ip 192.168.2.111 on 1

# 開啟通道 2 (設定額定電流 6A)
python src/caparoc_cli.py --ip 192.168.2.111 on 2 --current 6
```

---

### 3. off - 關閉通道

關閉指定通道。

**語法**:
```bash
python src/caparoc_cli.py [--ip IP] off CHANNEL
```

**參數**:
- `CHANNEL`: 通道編號 (1-4)

**範例**:
```bash
# 關閉通道 1
python src/caparoc_cli.py --ip 192.168.2.111 off 1

# 關閉通道 3
python src/caparoc_cli.py --ip 192.168.2.111 off 3
```

### 4. monitor - 即時監控模式

連續監控系統狀態，定期更新顯示。

**語法**:
```bash
python src/caparoc_cli.py [--ip IP] monitor [-c CHANNEL] [-i INTERVAL] [--clear]
```

**選項**:
- `-c, --channel`: 監控特定通道 (1-4)，不指定則監控所有通道
- `-i, --interval`: 更新間隔 (秒, 預設: 1.0)
- `--clear`: 每次更新清除畫面

**範例**:

#### 監控所有通道
```bash
python src/caparoc_cli.py --ip 192.168.2.111 monitor
```

**輸出範例**:
```
📊 即時監控模式 (按 Ctrl+C 停止)
============================================================

--- 更新 #1 (14:30:25) ---
系統電壓: 220.50 V | 總電流: 2.35 A
  CH1: 🟢 ON   1.20A    CH2: ⚫ OFF  0.00A    CH3: 🟢 ON   1.15A    CH4: ⚫ OFF  0.00A  

--- 更新 #2 (14:30:26) ---
系統電壓: 220.48 V | 總電流: 2.36 A
  CH1: 🟢 ON   1.21A    CH2: ⚫ OFF  0.00A    CH3: 🟢 ON   1.15A    CH4: ⚫ OFF  0.00A  
```

#### 監控單一通道
```bash
# 監控通道 1，每 0.5 秒更新
python src/caparoc_cli.py --ip 192.168.2.111 monitor -c 1 -i 0.5
```

**輸出範例**:
```
📊 即時監控模式 (按 Ctrl+C 停止)
============================================================
[0001] 通道 1: 🟢 ON | 電流:   1.20 A | 電壓: 220.50 V
```

#### 清屏模式
```bash
# 每次更新清除畫面（更乾淨的顯示）
python src/caparoc_cli.py --ip 192.168.2.111 monitor --clear
```

**停止監控**: 按 `Ctrl+C`

## 🐛 故障排除

### 問題 1: 無法連接到設備

**錯誤訊息**: `❌ 連接失敗`

**解決方案**:
1. 確認設備 IP 位址正確
2. 檢查網路連接
3. 確認設備電源開啟
4. 使用 ping 測試連通性：
   ```bash
   ping 192.168.2.111
   ```

### 問題 2: pycomm3 套件未安裝

**錯誤訊息**: `ModuleNotFoundError: No module named 'pycomm3'`

**解決方案**:
```bash
pip install pycomm3>=1.2.14
```

### 問題 3: 通道控制無回應

**症狀**: 開啟通道後電流仍為 0

**可能原因**:
1. 設備可能處於保護模式
2. 額定電流設定未生效
3. 負載未連接

**解決方案**:
1. 使用 verbose 模式查看詳細日誌：
   ```bash
   python src/caparoc_cli.py --ip 192.168.2.111 -v on 1
   ```
2. 檢查設備狀態指示燈
3. 嘗試重新連接設備

### 問題 4: 監控模式卡住

**症狀**: 監控畫面不更新

**解決方案**:
1. 按 `Ctrl+C` 停止程式
2. 重新啟動監控
3. 檢查網路連接穩定性
