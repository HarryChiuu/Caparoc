# CAPAROC 控制器 - 使用手冊

> **程式版本**: v3.7 (Phase 3.6.3 架構)  
> **更新日期**: 2026-05-14  
> **主程式**: `src/caparoc_controller.py`（CLI）+ `src/caparoc_backend.py`（裝置邏輯）

---

## 📋 概述

CAPAROC 控制器是基於 EtherNet/IP 協議的互動式控制程式，提供完整的斷路器模組管理功能。

### ✨ 主要功能

- ✅ **額定電流設定** - 使用 `init` 命令設定 1-20A 範圍
- ✅ **通道開關控制** - 使用 `on`/`off` 命令控制通道
- ✅ **狀態監控** - 查詢全域系統狀態與通道詳細資訊
- ✅ **即時監控** - 背景執行緒定期更新，支援靜默/顯示模式
- ✅ **多模組支援** - 自動偵測 1-16 個模組 (最多 64 通道)
- ✅ **IP 配置** - 啟動時可變更設備 IP 位址
- ✅ **自動重連** - 連線中斷時自動重試

### 🎯 適用場景

- 工業自動化控制
- 多通道負載管理
- 電流監控與保護
- 遠端設備控制

### 1. 額定電流設定

#### `init <通道編號> <電流值>`

設定指定通道的額定電流 (1-20A)。

**語法**:
```
init <ch> <amps>
```

**參數**:
- `<ch>`: 通道編號 (1 到總通道數)
- `<amps>`: 電流值 (1-20A)

**範例**:
```
🎮 > init 1 4
正在設定 CH1 額定電流為 4A...
✅ CH1 額定電流設定成功: 4A

🎮 > init 5 6
正在設定 M2.CH1 (#5) 額定電流為 6A...
✅ M2.CH1 (#5) 額定電流設定成功: 6A
```

**注意事項**:
- 使用 Config Assembly Read-Modify-Write 安全更新
- 設定後會自動驗證
- 支援多模組環境

---

#### `verify <通道編號>`

驗證指定通道的額定電流設定值。

**語法**:
```
verify <ch>
```

**範例**:
```
🎮 > verify 1
✅ CH1 額定電流: 4A

🎮 > verify 5
✅ M2.CH1 (#5) 額定電流: 6A
```

### 4. 即時監控

#### `monitor start [interval] [mode]`

啟動即時監控模式。

**語法**:
```
monitor start [interval] [mode]
```

**參數**:
- `[interval]`: 更新頻率 (秒)，預設 2 秒，範圍 0.5-60
- `[mode]`: 監控模式，預設 `silent`
  * `silent` - 靜默模式，僅在狀態變化時顯示警報
  * `display` - 顯示模式，定期顯示完整狀態

**範例**:

**靜默模式** (僅警報):
```
🎮 > monitor start 2 silent
🔄 監控執行緒啟動 (更新頻率: 2.0s, 靜默模式 (僅警報))
✅ 監控已啟動

# 只在有變化時顯示
⚠️  [14:32:15] 通道狀態變化:
   - CH1: OFF → ON (0.45A)
```

**顯示模式** (定期輸出):
```
🎮 > monitor start 2 display
🔄 監控執行緒啟動 (更新頻率: 2.0s, 顯示模式)
✅ 監控已啟動

[14:30:25] V:24.15V | I:1.20A | CH1:🟢0.45A CH2:⚫0.00A CH3:🟢0.75A CH4:⚫0.00A
[14:30:27] V:24.16V | I:1.21A | CH1:🟢0.46A CH2:⚫0.00A CH3:🟢0.75A CH4:⚫0.00A
[14:30:29] V:24.15V | I:1.20A | CH1:🟢0.45A CH2:⚫0.00A CH3:🟢0.75A CH4:⚫0.00A
```

**快速啟動** (使用預設值):
```
🎮 > monitor start
✅ 監控已啟動 (2秒更新, 靜默模式)
```

### 5. 連線設定

#### `setting`

開啟連線 IP 設定選單，提供四個子選項管理程式連線 IP 與設備硬體 IP。

**語法**:
```
setting
```

**互動選單**:
```
🎮 > setting

============================================================
⚙️  連線設定
============================================================
  目前連線 IP: 192.168.2.111
  預設 IP:     192.168.2.111  (config/device_config.json)
------------------------------------------------------------
  [1] 變更並連線       - 輸入新 IP，立即重連
  [2] 恢復預設值       - 使用 config.json 的 IP 重連
  [3] 存為預設值       - 將目前連線中的 IP 存入 config.json
  [4] 硬體 IP 修改     - 透過 CIP 修改設備 IP（成功後自動存檔並重連）
  [0] 返回主選單
============================================================

請選擇 [0/1/2/3/4]:
```

**子選項說明**:

| 選項 | 功能 | 是否重連 | 是否更新 config.json |
|------|------|----------|----------------------|
| `[1]` 變更並連線 | 輸入新 IP，立即重連 | ✅ 自動 | ❌（需手動 [3] 存檔） |
| `[2]` 恢復預設值 | 切回 config.json 記錄的 IP 並重連 | ✅ 自動 | ❌ |
| `[3]` 存為預設值 | 將目前連線 IP 寫入 config.json | ❌ | ✅ 立即寫入 |
| `[4]` 硬體 IP 修改 | CIP Class 0xF5 寫入設備 IP | ✅ 自動 | ✅ 自動 |

**典型使用流程**:
```
# 情境 1：切換到新設備
🎮 > setting
請選擇 [0/1/2/3/4]: 1
新 IP 位址 (或輸入 cancel 取消): 192.168.2.200
  ✅ 連線 IP 已設為 192.168.2.200
  🔄 使用新 IP 重新連線...
# → 連線成功後，若確認這個 IP 正確，再執行 setting [3] 存檔

# 情境 2：連線失敗時救回上次成功的 IP
🎮 > setting
請選擇 [0/1/2/3/4]: 2
  ✅ 已恢復為預設 IP 192.168.2.111
  🔄 重新連線...

# 情境 3：確認目前 IP 為長期預設
🎮 > setting
請選擇 [0/1/2/3/4]: 3
  ✅ 已將 192.168.2.200 設為預設 IP

# 情境 4：實體修改設備 IP（需 Npcap 環境）
🎮 > setting
請選擇 [0/1/2/3/4]: 4
  → 進入 CIP Class 0xF5 硬體 IP 設定子選單
  → 寫入成功後自動更新 config.json 並重連
```

**注意事項**:
- `[1]` 變更後不自動存檔，請使用 `[3]` 手動確認後存入
- `[2]` 的「預設值」來自 `config/device_config.json`，由 `[3]` 或 `[4]` 寫入
- `[4]` 需要設備支援 CIP Class 0xF5 寫入（部分環境需 Npcap）

## 🐛 故障排除

### 問題 1: 無法連接到設備

**錯誤訊息**:
```
❌ 裝置連線失敗!
   IP 位址: 192.168.2.111
   錯誤: 無法建立連線
```

**解決方案**:
1. 確認設備已開機
2. 檢查網路線連接
3. 確認 IP 位址正確
4. 使用 `ping` 測試連通性：
   ```powershell
   ping 192.168.2.111
   ```
5. 檢查防火牆設定 (Port 44818)
6. 確認電腦與設備在同一網段

---

### 問題 2: 通道控制無反應

**症狀**: 執行 `on 1` 後電流仍為 0

**可能原因**:
1. 額定電流未設定
2. 設備處於保護模式
3. 負載未連接

**解決方案**:
```
# 1. 檢查額定電流
🎮 > verify 1

# 2. 如果未設定，先設定額定電流
🎮 > init 1 4

# 3. 再次開啟通道
🎮 > on 1

# 4. 檢查狀態
🎮 > s
```

---

### 問題 3: 監控模式無輸出

**症狀**: `monitor start` 後沒有任何顯示

**原因**: 使用了靜默模式 (預設)

**解決方案**:
```
# 停止監控
🎮 > monitor stop

# 使用顯示模式重新啟動
🎮 > monitor start 2 display
```

---

### 問題 4: 連線中斷

**症狀**: 操作中出現連線錯誤

**解決方案**:
```
# 使用 reconnect 命令重新連線
🎮 > reconnect
```

## 📊 技術規格

- **通訊協議**: EtherNet/IP (CIP)
- **預設 Port**: 44818
- **支援模組**: 1-16 個
- **每模組通道**: 4 個
- **總通道數**: 最多 64 個
- **電流範圍**: 0-25.5A (讀取)
- **額定電流**: 1-20A (設定)
- **電壓範圍**: 9.0-30.5V
- **監控頻率**: 0.5-60 秒 (可調)
